# Masia Maths and Science Academy Website  

## **Overview**  
The official website for **Masia Maths and Science Academy (MMSA)** is designed to provide an interactive platform for students, parents, and stakeholders. The website showcases MMSA’s mission, programs, and achievements while providing essential resources, secure access to student results, and a streamlined application process.

---

## **Features**  
### **1. Home Page**  
- Overview of MMSA’s mission, vision, and key statistics.  
- Call-to-action buttons for applications, donations, and resource access.

### **2. About Us**  
- Comprehensive information about MMSA’s history, mission, and core values.  
- Strategic objectives to empower learners and improve STEM education.

### **3. Core Programs**  
- Detailed descriptions of MMSA’s initiatives, including:  
  - ICT Academy.  
  - Intervention Program (MIP).  
  - Career Guidance and STEM Girl Child Programs.  
  - Maths Pioneers and External Competitions.

### **4. Resources**  
- Study guides and question papers categorized by grades 8–11.  
- Downloadable PDFs for easy access.

### **5. Results**  
- Secure login and dashboard to view student performance.  
- Features include term-wise marks and downloadable reports.

### **6. Application Form**  
- Online application form for prospective students.  
- Upload options for required documents and automated confirmation messages.

### **7. Donation Page**  
- Easy-to-use form for donors to contribute to MMSA’s initiatives.  
- Transparent details on how funds are used to empower education.

### **8. Contact Us**  
- Contact information including email, phone numbers, and physical address.  
- Embedded contact form for inquiries.

## **Installation and Setup**  
### **1. Clone the Repository**  
```bash  
git clone https://github.com/occxlnce/mmsa.git  
```  

### **2. Navigate to the Project Directory**  
```bash  
cd mmsa-website  
```  

### **3. Install Dependencies**  
Depending on the tools used ( PHP):  

- For PHP:  
Ensure a server environment like XAMPP or WAMP is installed.
 
- For PHP:  
Place the project files in the server's `htdocs` directory and start the server.

### **5. Access the Website**  
Open a browser and navigate to:  
```
http://localhost:8000
```

## **Technologies Used**  
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap CSS, SCSS.  
- **Backend**: PHP
- **Database**: MySQL for storing student data, applications, and results.  
- **Other Tools**:  
  - Stripe/PayPal for donation processing.
